# Scripts

This directory contains helper scripts and command templates for reproducing the reported tables and figures.

- `rq1/` contains scripts for the two-party SAIA attack comparison.
- `rq2/` contains scripts for multi-client round-robin and PSL experiments.
- `rq3/` contains scripts for ConvNeXt-Tiny activation perturbation experiments.
- `figures/` contains scripts used to generate qualitative reconstruction figures.

Large checkpoints, raw datasets, temporary logs, and failed trial scripts are not included.
